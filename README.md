# Todoodle

Um simples sistema de gerenciamento de tarefas construído com TypeScript, Bun e Elysia.

## Layout

```
todoodle
├── apps
│   ├── api                # @todoodle/api
│   └── web                # @todoodle/web
└── packages
    ├── contracts          # @todoodle/contracts
    └── database           # @todoodle/database
```
